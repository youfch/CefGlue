# CEF Native Binaries Setup

CefGlue requires the native CEF (Chromium Embedded Framework) binaries to function. These are distributed as separate NuGet packages depending on your target platform.

## Package Sources

### Windows (`chromiumembeddedframework.runtime.win-x64` / `win-arm64`)

Windows CEF binaries are available on [nuget.org](https://www.nuget.org/packages/chromiumembeddedframework.runtime.win-x64/).

```xml
<!-- NuGet.config -->
<packageSources>
  <add key="nuget.org" value="https://api.nuget.org/v3/index.json" />
</packageSources>
```

```xml
<!-- .csproj -->
<ItemGroup>
  <PackageReference Include="chromiumembeddedframework.runtime.win-x64" Version="149.0.6" />
  <!-- or for ARM64: -->
  <PackageReference Include="chromiumembeddedframework.runtime.win-arm64" Version="149.0.6" />
  <!-- or the meta package (includes all available Windows platforms): -->
  <PackageReference Include="chromiumembeddedframework.runtime" Version="149.0.6" />
</ItemGroup>
```

### Linux (`cef.redist.linux64` / `cef.redist.linuxarm64`)

Linux CEF binaries are distributed via GitHub Releases. You need to add a custom NuGet source pointing to the release feed.

**Repository:** [github.com/youfch/cef.redist.linux](https://github.com/youfch/cef.redist.linux)

```xml
<!-- NuGet.config -->
<packageSources>
  <add key="nuget.org" value="https://api.nuget.org/v3/index.json" />
  <add key="cef-redist-linux" value="https://github.com/youfch/cef.redist.linux/releases/download/v149.0.4/index.json" />
</packageSources>
```

```xml
<!-- .csproj -->
<ItemGroup>
  <PackageReference Include="cef.redist.linux64" Version="149.0.4" />
  <!-- or for ARM64: -->
  <PackageReference Include="cef.redist.linuxarm64" Version="149.0.4" />
</ItemGroup>
```

> **Note:** The `index.json` file is auto-generated by the release workflow. If the URL doesn't work, you can download the `.nupkg` files directly from the [releases page](https://github.com/youfch/cef.redist.linux/releases) and use a local NuGet feed.

### macOS (`cef.redist.osx64` / `cef.redist.osxarm64`)

macOS CEF binaries are distributed via GitHub Releases.

**Repository:** [github.com/youfch/cef.redist.osx](https://github.com/youfch/cef.redist.osx)

```xml
<!-- NuGet.config -->
<packageSources>
  <add key="nuget.org" value="https://api.nuget.org/v3/index.json" />
  <add key="cef-redist-osx" value="https://github.com/youfch/cef.redist.osx/releases/download/v149.0.4/index.json" />
</packageSources>
```

```xml
<!-- .csproj -->
<ItemGroup>
  <PackageReference Include="cef.redist.osx64" Version="149.0.4" />
  <!-- or for ARM64: -->
  <PackageReference Include="cef.redist.osxarm64" Version="149.0.4" />
</ItemGroup>
```

## Cross-Platform Project Setup

For a project that targets multiple platforms, use conditional package references:

```xml
<ItemGroup Condition="$([MSBuild]::IsOSPlatform('Windows'))">
  <PackageReference Include="chromiumembeddedframework.runtime.win-x64" Version="149.0.6" />
  <PackageReference Include="CefGlue.BrowserProcess.runtime.win-x64" Version="149.7827.156" />
</ItemGroup>

<ItemGroup Condition="$([MSBuild]::IsOSPlatform('Linux'))">
  <PackageReference Include="cef.redist.linux64" Version="149.0.4" />
  <PackageReference Include="CefGlue.BrowserProcess.runtime.linux-x64" Version="149.7827.156" />
</ItemGroup>

<ItemGroup Condition="$([MSBuild]::IsOSPlatform('OSX'))">
  <PackageReference Include="cef.redist.osx64" Version="149.0.4" />
  <PackageReference Include="CefGlue.BrowserProcess.runtime.osx-x64" Version="149.7827.156" />
</ItemGroup>
```

## Version Compatibility

The CEF runtime version and the CefGlue version are independent. The table below shows the currently tested combinations:

| CefGlue Version | CEF Runtime Version |
|-----------------|---------------------|
| 149.7827.156    | 149.0.x             |

The CEF runtime version is specified by the `CefRedistVersion` property in `Directory.Build.props`. Make sure the CEF runtime version matches the version of the `chromiumembeddedframework.runtime.*` or `cef.redist.*` packages you install.

## Troubleshooting

### "Unable to find SubProcess"

This error means the BrowserProcess executable was not found in the output directory. Make sure you have installed a `CefGlue.BrowserProcess.runtime.*` package.

### Missing CEF native libraries

If you see errors about missing `libcef.dll`, `libcef.so`, or `libcef.dylib`, make sure you have installed the correct CEF native package for your platform.

### Linux locale files

On Linux, CEF locale files are located in the `locales` directory next to the executable. The `CefGlue.Common.targets` file automatically copies them from the `cef.redist` package.
